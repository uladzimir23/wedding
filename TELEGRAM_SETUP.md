# Telegram Setup — план интеграции

## Что получится в итоге

| Куда | Что отправляется | Кто видит |
|---|---|---|
| Приватная группа (молодожёны + организатор) | Полные данные гостя: имя, телефон, кол-во гостей, имена, транспорт, аллергии, ответ на викторину, аналитика | Только Игорь, Екатерина, организатор |
| Гостевой канал | Пожелание + имя автора | Все гости |

---

## Шаг 1 — Создать бота в BotFather

Ты уже открыл BotFather. Выполни:

```
/newbot
```

Придумай:
- **Имя** (отображается): `Igor & Katsiaryna Wedding`
- **Username** (уникальный, с суффиксом bot): `igor_katya_wed_bot`

BotFather выдаст **токен** вида:
```
7412345678:AAFxyz...длинная строка...
```

Сохрани его — он нужен в следующих шагах.

---

## Шаг 2 — Создать приватную группу (для молодожёнов + организатора)

1. В Telegram: создай новую группу — «Свадьба: гости»
2. Добавь в группу бота (`@igor_katya_wed_bot`)
3. Добавь Игоря, Екатерину, организатора
4. **Получи chat_id группы:**
   - Напиши в группе любое сообщение, например `/start`
   - Открой в браузере: `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
   - Найди поле `"chat":{"id": -XXXXXXXXX}` — это и есть chat_id (отрицательное число)

> ⚠️ Если getUpdates пустой — убедись что бот добавлен в группу и кто-то написал сообщение после добавления.

---

## Шаг 3 — Создать гостевой канал

1. В Telegram: создай канал — «Игорь и Екатерина 💍» (или публичный `@igor_katya_wed`)
2. Добавь бота в канал как **администратора** (права: публикация сообщений)
3. **Получи chat_id канала:**
   - Опубликуй любое сообщение в канале
   - Открой в браузере: `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
   - Найди поле `"chat":{"id": -100XXXXXXXXX}` — это chat_id канала

> Для публичных каналов chat_id можно заменить на `@username_канала`, например `@igor_katya_wed`

---

## Шаг 4 — Прописать переменные окружения

Создай файл `.env` в корне проекта (`wedding-starter/.env`):

```env
VITE_TG_BOT_TOKEN=7412345678:AAFxyz...
VITE_TG_ADMIN_CHAT_ID=-1001234567890
VITE_TG_GUEST_CHANNEL_ID=-1009876543210
```

> `.env` уже в `.gitignore` — секреты не попадут в git.

---

## Шаг 5 — Обновить telegram.ts

Файл `src/services/telegram.ts` будет иметь **две функции**:

```ts
// Отправка данных гостя → приватная группа
sendGuestData(lines: string[])

// Отправка пожелания → гостевой канал
sendWish(firstName: string, lastName: string, wish: string)
```

---

## Шаг 6 — Обновить QuizFunnel.tsx

В `handleFinish`:
1. Всегда отправляем полные данные в приватную группу
2. Если пожелание не пустое — дополнительно отправляем его в гостевой канал

---

## Итоговая структура переменных

```
VITE_TG_BOT_TOKEN         — токен бота (из BotFather)
VITE_TG_ADMIN_CHAT_ID     — chat_id приватной группы (отрицательное число)
VITE_TG_GUEST_CHANNEL_ID  — chat_id гостевого канала или @username
```
