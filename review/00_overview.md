# UI/UX Review — Свадебный сайт Игорь & Катерина
> Дата: 19.03.2026 | Ревьюер: Claude Code

---

## Краткое резюме

Сайт сделан с заботой и есть сильные части — но единого визуального языка нет.
Каждая секция выглядит как отдельный mini-продукт, сделанный в разное время разными руками.

**Три разных "духа" сейчас сосуществуют:**

| Дух | Где | Ощущение |
|-----|-----|----------|
| 🍎 Apple iOS | Location, WeddingTimeline, Contacts, Gifts | Минималистично, cold white, system font |
| 💒 Wedding classic | Hero, Welcome, Footer | Тёплое, script + serif, акварель |
| 📦 Generic card | FAQ, TelegramContest | Нейтрально, без характера |

**QuizFunnel** — вообще отдельный мир (full-screen wizard).

## Ключевые проблемы (топ-5)

1. **Цвета текста**: одни секции используют Apple-серые `#1C1C1E / #8E8E93`, другие — свадебные `var(--text-primary)` = `#5C1622`. Читатель чувствует разрыв подсознательно.

2. **Glassmorphism вразнобой**: opacity 0.45 / 0.52 / 0.68 / 0.78, blur 12px / 20px / 28px / 40px — нет стандарта.

3. **Заголовки секций**: три разных паттерна (большой serif h2, маленький uppercase label, скриптовое "24 апреля") — непредсказуемо.

4. **Отступы**: padding у каждой секции своё — Info-tab скачет ритмом.

5. **Border-radius**: 14px / 20px / 24px / 26px — глаз не привыкает.
